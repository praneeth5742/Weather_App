# Weather App

This is a responsive Weather Application developed as part of my Web Development & Designing Internship at Synent Technologies. The application provides real-time weather information for any city through a clean, modern, and user-friendly interface.

# Application Features

- Search weather information by city name
- Display current temperature
- Display weather conditions
- Show humidity levels
- Show wind speed
- Responsive design for desktop and mobile devices
- Clean and interactive user interface
- Real-time weather data

# Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- OpenWeather API

# How It Works

Users can enter the name of a city in the search box to retrieve its current weather information. The application sends a request to the OpenWeather API using the Fetch API, processes the received data, and displays details such as temperature, weather conditions, humidity, and wind speed in an easy-to-read format.

# Project Purpose

The purpose of this project is to understand API integration, asynchronous JavaScript, and data fetching using the Fetch API while developing a real-time weather application. It also demonstrates how external APIs can be integrated into web applications to provide dynamic and interactive user experiences.
